# Five-point d_osc scaling-law runs

Per-seed language-model validation perplexities used for the oscillator-dimension
scaling law (Table 4 rows at d_osc = 4 and 16, both datasets) and Figure 6. This
extends the causal-LM d_osc sweep from three points (d_osc in {2, 8, 32}) to five by
adding d_osc in {4, 16}, five seeds (0-4) each. Only d_osc changes across runs;
backbone, optimizer, LR schedule, tokenizer, train/val split, and epoch budget are held
fixed to match the other scaling-law points.

## Files

- `{wt2,ts}_dosc{4,16}_seed{0..4}.json` — one file per (dataset, d_osc, seed); each
  holds the final `val_ppl` for that run. 20 files = 2 datasets x 2 dimensions x 5 seeds.
  `language_modeling/dimension_scaling_analysis.py` reads these per-seed files directly
  and recomputes the scaling law; there is no precomputed aggregate to keep in sync.
- `verification_wt2_d8_seed0.json` — a single reproducibility spot-check.
- `scripts/` — `run_one_5pt.py` (train one seed), `run_dosc_sweep.sh` (the sweep),
  `aggregate_5pt.py` (optional: re-summarize the per-seed JSONs for inspection).

The model checkpoints produced by these runs are regenerated by training and are not
committed (see the top-level README). Only the small result JSONs above are shipped so
the scaling law and Figure 6 can be verified without re-running training.
